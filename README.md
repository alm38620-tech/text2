# بكسل أرينا — موقع تعريفي

موقع ثابت (Static) من أربع صفحات لمحل ألعاب وبلايستيشن في الرياض، بواجهة عربية كاملة من اليمين إلى اليسار.

## الصفحات

| الملف | الصفحة |
| --- | --- |
| `index.html` | الرئيسية: ترحيب، 3 مزايا، معرض صور، آراء العملاء |
| `services.html` | الخدمات والأسعار: 6 جلسات، إضافات، خطوات الحجز، أسئلة شائعة |
| `about.html` | عنّا: القصة، الأرقام، القيم، الخط الزمني، الفريق |
| `contact.html` | تواصل: بيانات التواصل، نموذج واتساب، خريطة توضيحية، أسئلة شائعة |

الملفات المشتركة: `style.css` للتنسيق، و`script.js` لقائمة الجوال وحركات الظهور ونموذج واتساب. الصور في مجلد `assets/`.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا يحتاج الموقع إلى سيرفر أو قاعدة بيانات أو أي تثبيت.

## ما يجب تعديله قبل النشر

كل البيانات التالية تجريبية ويمكن استبدالها بسهولة:

1. **رقم واتساب:** ابحث عن `966551234567` في ملفات HTML الأربعة واستبدله برقمك (بدون `+` أو مسافات). وفي `contact.html` عدّل أيضًا قيمة `data-wa="966551234567"` داخل النموذج.
2. **الهاتف والبريد:** `+966 55 123 4567` و`hello@pixelarena.sa`.
3. **العنوان:** «الرياض، حي العليا، طريق الملك فهد، مبنى 12 — الدور الأول» في `contact.html`، ورابط خرائط Google بجانبه.
4. **ساعات العمل:** السبت–الخميس 2 م–2 ص، والجمعة 2 م–3 ص.
5. **الأسعار:** جميع الأسعار في `services.html` بالريال وهي أمثلة قابلة للتعديل.
6. **روابط التواصل:** إنستقرام وتيك توك وإكس تشير حاليًا إلى الصفحات الرئيسية للمنصات؛ ضع روابط حساباتك.
7. **الصور:** استبدل ملفات `assets/*.svg` بصورك مع الحفاظ على الأسماء، أو حدّث مسارات `src` في HTML.

## ملاحظات

- شارة «مفتوح الآن» ثابتة وليست محسوبة من ساعة الجهاز.
- نموذج التواصل لا يخزّن البيانات؛ يجهّز رسالة واتساب فقط.
- الموقع لا يحتوي على تسجيل دخول أو قاعدة بيانات.
- التصميم متجاوب ويستخدم خصائص CSS المنطقية (`margin-inline`, `padding-inline`, …) لدعم RTL بشكل صحيح.
